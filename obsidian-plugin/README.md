# Task Tracker Sync — плагин Obsidian

Синхронизирует задачи таск-трекера с заметками Obsidian: заметка ↔ задача.
Разделение ролей — Obsidian владеет содержимым и свойствами «Проект»/«Метки»/«Связи»,
трекер владеет статусом/стадией/сроками/связями (приходят обратно как read-only
свойства).

## Сборка

```bash
cd obsidian-plugin
npm install
npm run build       # → main.js (production)
# или npm run dev   # watch-режим
```

## Установка в хранилище

Скопируйте `manifest.json`, `main.js` (и `styles.css`, если появится) в
`<vault>/.obsidian/plugins/task-tracker-sync/`, затем включите плагин в
Настройки → Сторонние плагины.

Для разработки удобно собирать прямо в папку плагина vault'а (симлинк или
`outfile` в `esbuild.config.mjs`).

## Настройка

1. В трекере: **Настройки пространства → Синхронизация с Obsidian** — создайте
   токен, скопируйте секрет.
2. В плагине (Настройки → Task Tracker Sync): укажите **URL сервера**, вставьте
   **токен**, при желании ограничьте **папку** задач.

## Свойства заметки (Properties)

Все свойства — на русском, как в трекере.

```yaml
---
Проект: Веб-сайт                # название проекта в трекере — ОБЯЗАТЕЛЬНО
Метки: [Баг, Срочно]            # → метки задачи (выбор из трекера)
Связи:                          # → связанные задачи (вход: добавляешь сам)
  - "[[Другая задача]]"
# ↓ типизированные связи из трекера (read-only, кликабельные):
Требует:        - "[[Инструкция]]"
Требуется для:  - "[[Приказ]]"
Утверждает: …
Утверждается: …
Дополняет: …
Дополняется: …
# ↓ ниже трекер пишет сам (read-only), руками не трогать:
ИД: …
Статус: 🟢 готово      # ⚪ не начато · 🔵 в работе · 🟢 готово
Стадия: …             # стадия (колонка доски)
Приоритет: 🔴 срочный  # ⚪ низкий · 🔵 обычный · 🟠 высокий · 🔴 срочный
Описание: …            # описание задачи из трекера
Подзадачи:      # список; выполненные — зачёркнуты
  - Собрать требования
  - с̶о̶г̶л̶а̶с̶о̶в̶а̶т̶ь̶   # (выполнена в трекере)
Срок: …
Пересмотр: …
Завершено: …
Исполнитель: …
Карточка: …     # ссылка на карточку в трекере
Обновлено: …
---
```

- **Проект** — можно вписать вручную, но удобнее командой «Выбрать проект заметки»
  (список проектов из трекера). Заметка без «Проекта» плагином игнорируется.
- **Метки** — командой «Добавить метку из трекера» (список меток трекера).
- **Описание** — описание задачи из трекера (read-only).
- **Связи** — исходящие связи типа «связано», которые ты добавляешь сам.
- **Связан с** — входящие связи «связано» из трекера (read-only).
- **Требует / Требуется для / Утверждает / Утверждается / Дополняет / Дополняется**
  — типизированные связи из трекера (read-only, кликабельные `[[ссылки]]`).
- **Подзадачи** — read-only список. Отмечать выполненными — в трекере; в Obsidian
  выполненные показываются **зачёркнутыми**.
- **Тело заметки** — твоё: это сам документ, плагин его не трогает.

## Кнопка и команды

Слева в панели Obsidian появляется иконка **Трекер** (↻) — клик открывает меню:
синхронизировать текущую/все, выбрать проект, добавить метку, импорт из трекера,
обзор готовности. Те же действия — в палитре команд (Cmd/Ctrl+P).

Отдельно «синхронизировать» жать обычно не нужно — заметка со свойством «Проект»
синхронизируется автоматически при сохранении.

### Команды

- **Синхронизировать текущую заметку** / **все задачи**
- **Выбрать проект заметки** — выбор проекта из списка трекера
- **Добавить метку из трекера** — выбор метки из списка
- **Создать заметки из задач трекера (импорт)** — обратный бутстрап: создаёт
  заметки `<Пространство>/<Проект>/<название>.md` для задач, у которых ещё нет
  заметки (Проект, Метки, Связи, read-only поля). Корневая папка — имя пространства
  из трекера (или заданная в настройках). Повторно не дублирует.
- **Сгенерировать обзор готовности (MOC)**
- **Открыть карточку в трекере**

## Как работает синхронизация

- Изменение заметки (`modify`/`create`/`rename`) → `POST /api/obsidian/upsert`.
  Отправляются только «входные» поля; тело заметки не передаётся.
- Анти-эхо: плагин шлёт изменение, только если изменились входные свойства, —
  обратная запись трекер-полей не вызывает повторной отправки.
- Удаление заметки в Obsidian **не влияет на трекер** — задача остаётся
  (архивируй её вручную на доске, если нужно).
- Статусы из трекера подтягиваются опросом `GET /api/obsidian/changes?since=…`
  (интервал настраивается). SSE-эндпоинт `/api/obsidian/stream` также доступен.
